# AI assistant plugin for Docusaurus

Add the [Biel.ai](https://biel.ai) AI assistant to your Docusaurus documentation. Help readers get answers grounded in your documentation, with links to the sources.

![Biel.ai AI assistant for Docusaurus](https://biel.ai/_next/image?url=%2F_next%2Fstatic%2Fmedia%2Fcarousel-02.d9a9a331.png&w=1200&q=75)

Biel.ai's official plugin adds conversational answers and documentation search to Docusaurus 3 sites.

*Note: A Biel.ai plan is required to use this plugin. Try it free for 14 days—no credit card required.*

## Key features

- AI assistant that answers questions from your connected documentation, with source links.
- Documentation search with an Ask AI handoff to the assistant.
- Integration with Docusaurus 3.
- Customizable to match your site's branding and user needs.
- **Connect** menu to connect indexed docs to Claude Code, Codex, and other MCP clients by copying an endpoint or setup command, or opening a supported client. Requires MCP enabled on an [eligible plan](https://biel.ai/pricing). [MCP setup guide](https://docs.biel.ai/integrations/mcp-server).
